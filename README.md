# 🪱 Neon Worm (TAN)

Sebuah game berbasis web interaktif bertema cacing neon (.io) yang dikembangkan secara mandiri menggunakan teknologi web modern tanpa bantuan framework eksternal. Game ini menguji logika pergerakan halus (*smooth movement*) dan kecerdasan buatan (*AI*) untuk karakter bot.

---

## 🚀 Fitur Utama
- **Smooth Gameplay:** Pergerakan cacing player yang dinamis, meliuk, dan responsif mengikuti arah mouse.
- **Smart Bot AI:** Karakter bot musuh yang mampu berbelok mulus, memindai makanan terdekat, dan memiliki radar pertahanan untuk menghindari tabrakan.
- **Neon Aesthetic:** Desain visual bertema gelap (*dark mode*) dengan efek cahaya lampu neon yang memanjakan mata.
- **Audio Imersif:** Dilengkapi dengan efek suara (*sound effects*) saat cacing memakan makanan atau meledak ketika menabrak.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5 Canvas:** Untuk melakukan render grafis 2D secara *real-time*.
- **Vanilla JavaScript:** Logika utama game, matematika vektor (pergerakan cacing), dan kecerdasan buatan bot.
- **CSS3:** Pengaturan tampilan halaman luar game dan efek neon.
- **Web Audio API:** Pengelolaan aset suara (`.wav`).

---

## 🕹️ Cara Bermain
1. Buka game melalui browser Anda.
2. Gerakkan **Mouse** atau kursor untuk mengarahkan cacing player.
3. Kumpulkan makanan sebanyak-banyaknya untuk menambah ukuran tubuh cacing.
4. Hindari menabrak tubuh cacing bot, dan jebak bot agar menabrak tubuh Anda!

---

## 📂 Struktur File
- `index.html` - Struktur utama halaman game.
- `script.js` - Logika game, pergerakan cacing, AI Bot, dan sistem skor.
- `style.css` - Desain tampilan dan efek neon.
- `makan.wav` - Efek suara saat memakan objek.
- `ledak.wav` - Efek suara saat terjadi tabrakan/kalah.
